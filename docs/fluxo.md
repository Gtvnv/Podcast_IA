# Fluxo da esteira

```
Pauta (ChatGPT) -> Roteiro (ChatGPT) -> Voz (ElevenLabs) -> Edição (CapCut)
                                  \-> Capa (Midjourney) ----^
```

| Etapa | Entrada | Saída |
| :--- | :--- | :--- |
| 1. Pauta | tema | título e estrutura |
| 2. Roteiro | estrutura | `output/roteiro.md` |
| 3. Voz | texto de narração | `output/audio_sintetizado.mp3` |
| 4. Capa | tema e estilo visual | `assets/cover.png` |
| 5. Edição | áudio bruto, trilha | `output/podcast_editado.mp3` |

## Checklist antes de publicar

- [ ] Roteiro revisado quanto a fatos técnicos
- [ ] Voz sem violação de direitos de terceiros
- [ ] Trilha com licença livre
- [ ] Aviso de conteúdo gerado por IA na descrição
- [ ] Capa em 3000x3000 px
